**剔除规则**（进入寻优候选前）：

- 账户配置不进：费率、初始资金、月提取（monthly_withdraw_base）、T盈利提成（t_profit_withdraw_pct）、min_t_amount、warmup_days —— 资金行为不是策略参数，且直接污染净值目标。

## 3. 两个现实锚点（方案立意依据）

### 3.1 历史教训：砍半优先于找参数

RESEARCH_MOMENTUM_SLOT.md 的硬结论：

- 两次寻优 best_params 的 OOS 全崩（-53.7% / -41.4%），**唯一通过 OOS 的是不寻优的 L2 基座（+1.9%）**——样本内寻优在该策略上目前是负价值；
- 参数平原极窄，样本内最优孤立在尖峰上；10 个参数微调可让 OOS 从 +1.9% 摆到 -41.4%；
- 坍塌点 = 退出止损组（exit_need 衰退信号满足数 / partial_exit_pct 首次减仓比例），即**重要性最高的组恰是过拟合源**——"重要性高"不等于"该调"。

因此本方案把"砍一半"从附属产出升级为**第一目标**：先把自由度从 ~60 砍到 ~20-30，再在收窄空间内寻优。DOF 减半是防过拟合三件套（多窗口 / λ / dd_floor）之外的结构性第四道防线。

### 3.2 现实差距：当前基座大幅跑输基准

| 组合 | 全区间（2025-01~2026-08） | 同期中证500 |
|---|---|---|
| L2 基座（当前正式参数，创科池） | +44.5% | 复合约 **+84%**（样本内段 +70.3% × OOS 段 +8.3%） |

差距 ~40pt，其中约 27pt 是创科池相对中证500 的风格劣势（等权指数对比：用户池 +43.5% vs 中证500 +70.3%，样本内段）。"明显跑赢中证500" 意味着把 -40pt 翻成 +10pt：**扩域到中证500消掉风格差是第一步，剩余要靠机制层真实改进**。这不是轻松目标，阶段 0 锚点先量化扩域后的真实起点。

```
阶段0 新锚点 → 阶段1 OAT敏感性普查 → 阶段2 确定性砍半 → 阶段3 半区寻优 → 阶段4 选股无关验收
   └──────────────── L-日线骨架层（2018-01~2026-08，约8.6年牛熊全周期）────────────────┘
                                                └─ L-分钟做T层：单列二阶段（独立砍半/寻优/验收），等中证500分钟线补齐后启动
```

两条铁律贯穿全程：

1. **每一阶段的产出都必须赢当前基座**（OOS 口径），赢不了即止、报告、不自动回退改代码（沿用方法论 §9.6）；
2. **无后视镜**：任何新实验沿用 T-1 选池基准日语义，不引入未来数据。

## 5. 阶段明细

### 5.1 阶段 0：新锚点（3 个回测，零寻优）

| 任务 | 配置 | 回答的问题 |
|---|---|---|
| BT-D1 | 中证500 成分域 + L2 参数 + 日线 2018-01~2026-08 | 扩域后基座离中证500 还有多远（新基座锚） |
| BT-D2 | BT-D1 + pool_gate（池级趋势开关）开启 | gate 在长区间/新域的增量 |
| BT-D3 | 中证500 域随机 300 子集 + L2 参数 | "池内选股 luck"的方差量级（跨池验收的预检） |

- 后续所有阶段以 **BT-D1 为基座锚**（替代 L2 分钟线基座）。
- universe_auto 预筛参数固定同一组中性值（auto_* 隔离原则）。

### 5.2 阶段 1：OAT 敏感性普查（覆盖全部冻结参数）

- 对 L-日线层 ~40 项候选做**单参数扫描（OAT）**：其它参数固定 BT-D1，单参数走 5 档网格 → 每参数 4 次回测，共 ~160 次。
- 每参数产出两个度量：
  - **I(p) 敏感度幅度**：5 档 score 极差（主度量）；
  - **平坦度**：峰值档孤立度 = (最优档 score − 次优档 score) / 全域极差；> 0.5 判为**孤立尖峰**。
- 交叉校验：已有 Optuna study 覆盖的参数直接取 `optuna.importance.get_param_importances`（fANOVA，零额外回测）对照 OAT 排名，分歧大的参数标记复核。
- 这一步即"把冻结的 54 项重新算上"：不是直接放回寻优空间，而是**先让数据投票**。

### 5.3 阶段 2：确定性砍半（规则 v1，完全可复现）

输入：L-日线层候选集 P（|P| = N ≈ 40），每参数带 I(p) 与孤立尖峰标记。

1. **尖峰否决**：孤立尖峰参数强制进"砍"名单（历史坍塌点即此类）；
2. 幸存者按 I(p) 降序补足到 **⌈N/2⌉**；
3. 并列决胜：(组序, 参数名字典序)，保证同数据同结果；
4. 幸存者不足一半时**宁可砍更多，不回收尖峰**；
5. 砍掉者 → `frozen=True` 固化（形态见决策点 D4；止损类安全参数锁保守档，如 atr_stop_k（ATR硬止损倍数）= -6 灾难保护档，与 RESEARCH 待办 #7 同方向）；
6. **消融验收**：砍半配置（其余保持 BT-D1 默认）vs 全参数配置，OOS + BT-D3 池对照；超额差不显著劣化才通过。劣化 → 报告用户裁决，**不自动改规则**（规则进入 v2 讨论由用户发起）。

**砍半时点在寻优之前**：OAT 以基座为锚、一次一个参数，本身不产生过拟合；"先全空间寻优再按结果砍"会重蹈前两次覆辙。

### 5.4 阶段 3：半区联合寻优（沿用分组坐标轮换架构）

- 保留半区（~20 项）按现有组分 ~6-8 组，rounds × 每组独立 Optuna study，trial 预算按组重要性分配；
- 防过拟合三件套必开：n_windows ≥ 3（长区间建议 5 窗）、λ ≥ 0.5、dd_floor（回撤熔断线）；
- 目标函数：**相对基准的年化超额**（口径见 §6），跨窗惩罚作用于每窗超额；
- 判定：OOS 必须赢 BT-D1；per_group_best 增量链组级消融照跑（成本 5 次回测/轮，价值最高）；
- 敏感组（退出/止损类）搜索范围收窄沿用既有纪律。

### 5.5 "选股无关"的核心手法：池 = 基准域

把候选池设为**中证500成分域**时，池子与基准重合：

- 池内动量排序是策略机制的组成部分，而域本身与基准相同 → **超额只能来自轮动 / 止损 / 仓位管理 / gate 等机制，无法来自"选对了池"**；
- 历史佐证：池子风格差异被等权指数对比证实只有 5~11pt（扩域后归零），而参数-环境错配的执行损耗才是主因——"池=基准域"恰好把前者中和、把后者暴露给寻优；
- 中证500 两段全场最强（RESEARCH §4）→ 该域是动量机制的天然主场，跑赢它的部分即机制净贡献。

auto_*（universe_auto 预筛系）在此原则下**隔离不寻优**：选股无关要求池子维度被固定与被测试，而非被优化。

### 5.6 阶段 4：选股无关验收（跨池协议）

同一最终参数集，跑 6 个池（日线全区间）：

| 池 | 目的 |
|---|---|
| 全 500 只 | 主池 |
| 随机 300 × 2（不同种子） | 子集稳定性 |
| 随机 150 × 2（不同种子） | 小池压力测试 |
| 现有创科 200 池 | 域外泛化 |

判据三档见 §9 D3。未通过的处置：回阶段 3 收窄重寻，或如实接受"策略对池有偏好"的结论——**不通过不改判据**。

### 5.7 L-分钟做T层（二阶段，挂起条件）

触发条件：中证500 分钟线补齐（当前 147/500）。

- 独立 OAT 普查（~20 项 × 4 档 ≈ 80 次分钟线回测，区间受限 2025 起）→ 独立砍半保留 ~10 项 → 分组寻优（目标：分钟段内做T净贡献，需对照日线形态同段基线）；
- 做T层是执行层，与"选股无关"正交，不参与阶段 4 跨池验收；
- 注意：分钟段结论的 OOS 说服力受区间长度限制，报告需如实标注。

## 6. 目标函数设计

### 6.1 超额口径（需实现，见 §8）

- 现状：optimizer `METRICS` 仅 annual_return / sharpe / calmar / total_return（绝对口径）；
- 新增：`excess_annual` = 策略年化 − 中证500 年化（同区间，几何口径候选：`(1+r_s)/(1+r_b)−1`，口径二选一见 §9 可选项）；
- 跨窗惩罚作用于每窗超额：`score = mean(每窗超额) − λ×std(每窗超额) − 大惩罚(任一窗击穿 dd_floor)`。

### 6.2 现存短板与可选升级

- 现有多窗口是**同一条权益曲线切段**（`_window_metrics`），非独立分段回测，λ 惩罚对"不同环境"的覆盖弱——升级候选：按日历切窗独立回测 / walk-forward 滚动多折（RESEARCH 方向 #1）；
- 是否本次顺手升级：见 §9 可选项 B（升级会放大算力 2~3 倍）。
