## 1. 研究起点与问题定义

原始痛点：条件选股为"静态过滤 + 随机抽样"，池子与策略无关，策略在池内"矮子里拔将军"。
本轮演进：动态选股（universe\_auto，无后视镜 T-1 预筛 + 空仓滚动重选）→ 寻优 → 验证 → 归因的完整闭环。

## 2. 三轮寻优对比：样本内增益不可信 ✅

| 寻优                     | 约束                                                   | 样本内最优                | OOS 表现                           |
| ---------------------- | ---------------------------------------------------- | -------------------- | -------------------------------- |
| `opt_f61430c9c390` 无约束 | annual\_return · 3窗 · λ=0.5 · 无dd\_floor             | 年化 +163% / 夏普 2.66   | **-53.7%，3窗全负，overfit=high**     |
| `opt_b5fdfb0c0651` 收窄  | total\_return · 4窗 · λ=1.0 · dd\_floor=-0.35 · 退出组收窄 | 年化 +140.8% / 夏普 2.67 | **-41.4%，前2窗正后2窗负，overfit=high** |
| **L2 基座（不寻优）**         | —                                                    | 全区间 +44.5% / 夏普 0.82 | **+1.9% ✅ 唯一通过 OOS**             |

### 结论

- ✅ **两次寻优的 best\_params 在 OOS 上都输给不优化的 L2 基座**——样本内寻优在该策略上目前是负价值。

- ✅ **参数平原极窄**：本轮 best 相对 L2 仅 10 个参数微调（`mom_short（短周期动量）`15→20、`t_ratio_base（T单比例基准）`25→15 等），OOS 从 +1.9% 摆到 -41.4%。样本内最优孤立在尖峰上。

- ✅ **收窄约束有效但不彻底**：样本内最优从 +163% 压到 +141%（dd\_floor/λ 起效）；OOS 从"3窗全负"改善为"前2窗正后2窗负"（约 2026-03\~05 段转正），但 2026 年中后普跌段依然崩。

- ✅ **槽位组的结构性信号**：收窄约束下（`pool_n（候选池大小）`≥8 + `max_holdings（最大持仓只数）`≤5，共 60 个轮动结构 trial）**没有一个能打败基座的 6/6 满配死拿**——强势段里"集中死拿"碾压"分散轮动"，样本内评估天然偏爱死拿（选择偏差）。

## 3. 组级消融：OOS 坍塌点精确定位 ✅

OOS 段 = 2026-03-04 \~ 2026-08-31（split 的后 30%）。坐标轮换的 per\_group\_best 天然构成增量链，逐组累积回测：

| 配置     | 累积改动            | OOS 年化     | OOS 回撤     | 夏普        |
| ------ | --------------- | ---------- | ---------- | --------- |
| L0     | 全回退基座           | **-41.8%** | -30.2%     | -0.98     |
| L1     | +选股排序组          | -12.1%     | -29.0%     | +0.11     |
| **L2** | +槽位建仓组          | **+4.0%**  | **-24.0%** | **+0.55** |
| L3     | +退出止损组          | -45.2%     | -37.2%     | -0.77     |
| L4     | +做T正向T（=上轮best） | -53.7%     | -35.1%     | -1.36     |

### 结论

- ✅ **坍塌点 = 退出止损组**（L2→L3 一跳 -49 个百分点）：`exit_need（衰退信号满足数）`2→3 + `take_profit_pct（止盈比例）`关零 + `partial_exit_pct（首次减仓比例）`50→30 = "死拿"形态，样本内最优、OOS 灾难。

- ✅ **L1+L2 是真金**：OOS 从 -41.8% 拉到 +4.0%，下跌市里验证为正的改进（与换池检验互相印证）。

- ✅ **L0 基线 OOS -41.8% 是最重要锚点**：证明瓶颈不在"参数被调坏"，而在**策略形态缺少市场状态适配**——任何静态参数都救不了不适合的环境。

## 4. 风格归因：避险假设证伪 + 中盘发现 ✅

各池等权日收益指数（后复权日线，2024-12 起）：

| 组合             | 样本内段（至26-03） | OOS 段     |
| -------------- | ------------ | --------- |
| 用户池（科创+创业200只） | +43.5%       | -2.8%     |
| 银行（申万L1）       | +18.0%       | **-4.5%** |
| 沪深300          | +42.8%       | +2.2%     |
| **中证500**      | **+70.3%**   | **+8.3%** |

### 结论

- ❌ **"资金避险去银行红利"假设证伪**：OOS 段银行比用户池还差——那是普跌缩量市，不是红利风格市。

- ✅ **池子风格劣势真实但只有 5\~11 个百分点**；真正把 -2.8% 放大到 -23%（L0）的是参数-环境错配的执行损耗。

- ✅ **中证500 两段全场最强**：人工锁定科创+创业排除了中盘动量域——扩域（`auto_index（候选域指数）`放开）是最有数据支撑的池子改进方向。

## 5. 交易级归因：亏损结构拆解 ✅

BT-A（L2 参数全区间，1155 笔卖出）：

| 卖出类型          | 笔数  | 合计 pnl       | 胜率   |
| ------------- | --- | ------------ | ---- |
| 止损（ATR移动/固定）  | 320 | **-459.7 万** | 12%  |
| 衰退退出（首次减/二次清） | 77  | -78.4 万      | 25%  |
| 做T高抛          | 704 | **+317.8 万** | 67%  |
| 止盈/过热减仓       | 54  | +376.1 万     | 100% |

OOS 段：止损 117 笔 **-227.7 万、胜率 9%**；**卖出侧合计 +19.9 万（正）**。

### 结论

- ✅ **衰退退出（`exit_need`/`partial_exit_pct`）没有失职但被截胡**：ATR 移动止损盘中实时优先触发，多数持仓活不到衰退信号齐备；且首次减仓→二次清仓间隔**中位 0 天**，渐进式退化为一次性全清。

- ✅ **亏损真因 = 开仓即错（环境税）**：卖出侧合计为正，亏损在"下跌市 170 连错开仓 + 持仓浮亏"。个股级风控只能截断单笔，止不住系统性失血。

- ✅ **做T层（`t_mode（做T机制）`=grid）是盈利时段的主力**（+317.8 万），但下跌市里反向放大（OOS 段做T组改动再补刀 -8 个百分点）。

## 6. universe\_auto 能力边界 ✅

BT-B（同 L2 参数，动态池 top30 vs 静态 200）：-17.2% vs +44.5%，**S1 从 2025-01 持有到 2026-08-28 才触发换池**。

- ✅ **universe\_auto = 池子保鲜机制，不是市场择时**：只要池内还有票金叉，就继续交易；"无票过门槛→空仓"只在全市场级极端熊市触发。

- ✅ BT-B 跑输的混淆变量：动量 top30 = 高位股池（2024-12-31 时点最强），遭遇动量崩溃均值回归；与静态 200 随机池不可直接对比。

## 7. 当前采纳状态 ✅

- **正式参数 = L2**：基座 + 选股排序组（`mom_short`15/`mom_mid`90/`w_short`0.3/`w_mid`0.3）+ 槽位建仓组（`pool_n`6/`max_holdings`6/`base_pct_max`45/`base_pct_min`10/单票上限35%）。

- 依据：唯一通过 OOS 检验（+1.9%）+ 换池正收益 + 全区间 +44.5%。

- 槽位参数保持 6/6 的含义：强势段"满配死拿"碾压轮动（60 trial 证明）；它与轮动结构是**两种市场状态的两种最优形态，静态参数只能二选一**。

## 9. 方法论沉淀（可复用流程）

本轮跑通的验证闭环，后续任何策略调参都按此执行：

1. **寻优**：分组坐标轮换；防过拟合三件套必开（多窗口 n\_windows≥3、λ≥0.5、dd\_floor）；敏感参数组（退出/止损类）搜索范围必须收窄。
2. **三关**：overfit\_risk → OOS 验证 → robustness（换池/换时段）；任一不过，参数不采纳。
3. **组级消融**：用 per\_group\_best 增量链逐组累积回测 OOS，定位坍塌点——成本仅 5 次回测，价值最高。
4. **风格归因**：池子等权指数分段对比（样本内 vs OOS），区分"策略问题"与"环境问题"。
5. **交易级归因**：卖出侧按类型聚合 pnl + 胜率，区分"退出失职"与"进场即错"。
6. **判定准则**：寻优 best 必须与"不优化的基座"做 OOS 对照——赢不了基座的寻优是负价值。
