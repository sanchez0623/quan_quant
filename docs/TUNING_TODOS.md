# 待调优硬编码值清单（A 类）

> 记录动量趋势+做T回测链路中"拍脑袋定值"的硬编码参数（无客观推导依据，纯经验值）。
> 后续需要逐一调整：参数化进 `param_schema` 或 `RiskConfig`，再交给 Optuna 寻优。
> 状态：A 类 7 项已于 2026-08-26 全部落地（详见文末"实施记录"）；参数均已进入 `param_schema` / `RiskConfig` / `DEFAULTS`，可经 Optuna 寻优。

## A 类：拍脑袋值（7 项）

| # | 位置 | 当前值 | 问题 | 建议方向 |
|---|---|---|---|---|
| 1 | `momentum_t.py` 波动状态分档（`vol_ratio`） | 高波 `>1.3` / 低波 `<0.75` | 两档阈值纯经验，对低波银行股与高波科创板用同一把尺子 | 改滚动分位数定档（如 >0.7 分位=高波、<0.3=低波），每只票自适应 |
| 2 | `momentum_t.py` 高低波网格调整系数 | 高波 ×1.3 / 低波 ×0.8 | 调整系数拍脑袋，且与分档阈值耦合 | 参数化 `vol_grid_hi/lo`，寻优 |
| 3 | `momentum_t.py` T比例波动乘数 | 高波 ×4/3 / 低波 ×2/3 | 两档跳变不平滑 | 参数化或改线性插值 |
| 4 | `momentum_t.py` T比例日内衰减 | `0.7 ** t_count` | 衰减系数经验值 | 参数化 `t_decay`，寻优 |
| 5 | `runner.py` T/减仓兜底比例 | `33.3333`%（1/3） | 策略未传 t_ratio/reduce_pct 时的引擎兜底值，写死在引擎 | 依赖信号列已有值，默认值参数化 |
| 6 | `momentum_t.py` 预热期 `warmup_days` | 300 | 按"最长回看+缓冲"估算，非精确值 | 保持（只影响数据加载量，不影响正确性）；如需精确可改 = 最长回看参数 + 缓冲 |
| 7 | `risk.py` RiskConfig 默认组 | 止损8% / ATR×2.0 / 熔断30% / 日内4次 | 教科书默认，对"做T+动量"风格偏松（ATR 2 倍在高波动票上反复扫损；4 次/日对网格偏紧） | ATR 倍数建议 2.5~3；次数与策略 `max_t_times` 对齐；其余寻优 |

## 备注

- **B 类（有客观依据，不列入）**：费率六项（佣金万0.5/印花税万5/经手万0.341/证管万0.2/过户万0.1）、网格阈值下限 0.4%（=往返成本×安全倍数）、最小T金额 2 万（=最低佣金非线性临界保护）、现金缓冲 7.5%（=6个月出金额）、A股制度值（100股整手/T+1/交易日转自然日 7:5）。
- **C 类（经典技术指标参数，社区共识，已在 param_schema 可调可寻优）**：MACD 12/26/9、趋势慢线 60、MA20、ATR 14、动量窗口 20/60/120、底仓 10~70%、加仓递减 0.5、过热乖离 3.0×ATR、减仓 33%。

## 实施记录（2026-08-26）

| # | 落地内容 |
|---|---|
| 1 | 波动状态改滚动分位数定档：新增 `vol_q_hi`（默认0.7）/ `vol_q_lo`（默认0.3），`atr_pct` 相对滚动分位数计算连续 `vol_pos ∈ [0,1]`（每只票自适应），高于高波分位→1、低于低波分位→0，样本不足按中性0.5处理；替换原 `vol_ratio`（相对滚动中位数比值） |
| 2 | 网格调整系数参数化：新增 `vol_grid_hi`（默认1.3）/ `vol_grid_lo`（默认0.8），由 `vol_pos` 线性插值，与分档阈值解耦 |
| 3 | T比例波动乘数参数化+线性插值：新增 `t_vol_hi`（默认4/3）/ `t_vol_lo`（默认2/3），`vol_mult = t_vol_lo + (t_vol_hi - t_vol_lo) × vol_pos`，消除两档跳变 |
| 4 | T比例日内衰减参数化：新增 `t_decay`（默认0.7），`ratio × t_decay ** t_count` |
| 5 | `runner.py` 兜底比例参数化：新增 `DEFAULTS["t_ratio_fallback"]` / `["reduce_pct_fallback"]`（默认33.3333，可被配置覆盖）；信号列已有值时优先用信号值 |
| 6 | `warmup_days` 改为属性动态推导：= 最长回看参数默认值 + 缓冲180（≈ trend_ma+vol_window 默认值之和），默认仍为300，仅影响数据加载量 |
| 7 | `RiskConfig` 默认组：`atr_multiplier` 2.0→2.5（建议区间2.5~3）；`max_intraday_trades` 未显式配置时自动对齐策略 `max_t_times`（runner 与 API `validate_backtest_config` 双层落地），前端默认风控同步（`atr_multiplier:2.5`，日内次数留空自动对齐）；止损8%与熔断30%保留待寻优 |
