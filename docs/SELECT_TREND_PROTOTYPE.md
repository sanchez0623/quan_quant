# 动态加速启动选股（select_trend）原型方案

> 状态：原型已实现（P1 动态选股），跨时段验证未过护栏，需继续迭代
> 日期：2026-08-28
> 目的：回答"股票池不固定、持仓不足时动态按动量趋势标准补入"是否可行
> 关联文档：`MOMENTUM_T_AUDIT.md`（过拟合根源）、`OPTIMIZE_AND_AI_PLAN.md`（P0 跨池/跨时段护栏）
> 源码：`backend/app/engine/strategies/select_trend.py`

## 1. 动机

现有 `momentum_t` 是**固定池**策略：`universe` 内 top_n 选股。用户提出：

> 如果股票池不是固定的，而是持仓不足最大持仓数时，动态根据动量趋势选股标准，选出符合**加速段启动**的股票加入股票池买卖，这样如何？

核心诉求 = **动态补入 + 加速启动形态**，而非固定池 + 等权持有。

## 2. 原型设计

### 2.1 机制：引擎 max_holdings 天然实现动态补入

候选池 = `config.universe`（可放大到数百只）。引擎在"持仓 < max_holdings"时才允许开新仓，因此只要候选池里有票触发条件就会自动补入——**不需要单独"动态股票池"概念**，条件型入池 + 引擎持仓上限即等价于动态选股。

### 2.2 三个核心条件（"加速段启动"）

| # | 条件 | 计算 | 备注 |
|---|---|---|---|
| ① 金叉 | MACD DIF > DEA | `add_macd` | 趋势转强 |
| ② 突破 | 收盘创前 `breakout_n` 日新高 | `close > prior_high`（前 N 日最高，不含当日） | 平台突破 |
| ③ 相对强度 | RPS 处横截面前 `rps_top` 分位 | `close/close.shift(rps_n)-1` 逐日横截面分位 | 全市场选强 |

满足 **≥ entry_need 个**（默认 2）**且条件首次成立**时发开仓信号（`entry_event = entry & ~entry.shift(1)`，避免持仓中重复加仓刷单）。

### 2.3 退出

收盘跌破慢线 `ma_slow` 清仓；止损由引擎风控（ATR 止损等）负责。

### 2.4 点时一致性（无未来函数）

所有特征用当日收盘已知数据（`close`、`dif`、`dea`、`prior_high`、`rps`），信号当日 bar 生成、次日开盘成交（引擎语义），与 A1 修复口径一致。

### 2.5 周期与预热

- `periods = ["daily"]`：纯日线，避免对全市场做 5 分钟特征（数据/算力成本）。
- `warmup_days = max(ma_slow, breakout_n, rps_n, macd_slow) + 60`：保证特征窗口充足。
- 多档日线数据时把 `max_t_times` 硬置 0（无做T）。

### 2.6 参数表

| key | 默认 | 范围 | 说明 |
|---|---|---|---|
| macd_fast/slow/signal | 12/26/9 | - | MACD 金叉 |
| ma_slow | 20 | 5~60 | 趋势慢线（退出） |
| breakout_n | 20 | 5~60 | 新高突破窗口（日） |
| rps_n | 20 | 5~60 | 相对强度窗口（日） |
| rps_top | 0.5 | 0.1~1.0 | RPS 前多少分位算强 |
| entry_need | 2 | 1~3 | 至少满足几个条件 |
| base_pct | 30% | 5~90 | 开仓资金占比 |
| max_adds | 1 | 0~4 | 最大加仓次数 |

## 3. 跨时段验证（P0 护栏预检）

按 P0 原则，动态选股参数必须同时过 **2024 / 2025 / 2026**，否则照样"背答案"。

**候选池**：创/科创板 parquet 全库中，窗口内 bar 数足够的约 100 只（`select_trend` 候选池扫描按 300/301/688 前缀 + 最低 bar 数过滤）。

**扫描结果（原型实测）**：

| 年份 | 默认参数年化 |
|---|---|
| 2024 | -14.6% |
| 2025 | -20.3% |
| 2026（至 8 月） | +42.7% |

**结论**：默认参数 2026 表现好（+42.7%）但 2024/2025 亏损，**无参数组合三窗全正 → 护栏拦截**。即"2026 跑得好"大概率是当年的市场环境巧合，不具备跨年稳健性，**原型暂不可作为正式策略投入使用**。

## 4. 待改进方向（下次迭代）

1. **退出太晚**：跌破 ma_slow 才清仓，加速段见顶回落时回吐过多——考虑"跌破加速启动参考线/上涨斜率走平即减"。
2. **相对强度窗口固定**：rps_n 固定 20 日，可能错过中长线强势；可做双窗口 RPS 合成。
3. **入场过频**：entry_need=2 条件下票多时换手高；可加"加速段确认"（如突破后不回落）过滤。
4. **候选池幸存者偏差**：约 100 只候选仍是从现库挑选，跨 2024 前没有上市的票天然缺席，验证结论只能代表"现存票"。
5. **日线粒度局限**：加速段启动多在盘中确认，日线信号慢半拍；若数据/算力允许可试 minute5 版（成本高）。

## 5. 与对比实验（TREN_T）的关系

- 动态选股是**池维度**的探索，对比实验是**策略层（趋势×做T）**的探索，正交。
- 对比实验结论"砍 T 层 + 趋势层日线评估"若成立，可反哺动态选股（不做T、日线时钟），降低原型复杂度。
