> 目标：盘点当前项目的每个功能——重要性评级、可调整方向、可放弃方向，并脑暴新方向。
> 结论先行，每个模块给明确建议（保留 / 调整 / 放弃 / 新增），附理由。

## 0. 一页结论（TL;DR）

| 动作             | 对象                                               | 理由                                                   |

| **已删除**        | select\_trend（原型策略）                              | 2026-09 已移除：中间产物，选股思路已被 momentum\_slot 候选池吸收，无独立回测价值 |

## 3. 重点模块深度分析

### 3.1 策略层 —— select\_trend 已删除

**状态：2026-09 已彻底删除（代码 + 测试 + 文档）。**

删除理由（留存记录）：

- 定位是"全市场条件选股原型"，选股逻辑（金叉+突破+相对强度按 entry\_need 计数）与 momentum\_slot 的**加速启动候选池**思路同源，已被 slot 策略覆盖。

- 项目实际回测/寻优/实盘主线是 momentum\_slot / momentum\_t；select\_trend 无独立参数迭代价值，留在策略列表只会增加选择噪音。

- 其动量特征口径与 momentum\_core 同源，所需能力均已由 `momentum_core.py` 提供，删除不影响研究链路。

其余策略定位建议：

- **momentum\_slot**：主策略（做T+动态选股+槽位），一切新能力优先落这里。

- **momentum\_t**：动量趋势对照主线，保持简单、不叠加做T复杂度。

- **ma\_cross / grid\_t**：视为基线对照（基准线、回测正确性冒烟测试用），UI 沉底，不在寻优默认池出现。

### 3.2 参数寻优 —— 防过拟合是最大短板

现状（`optimizer.py`）：

- 分组坐标轮换（rounds 轮 × 每组独立 Optuna study），减少组合爆炸

- 多窗口稳健目标：`score = mean(每窗) − λ×std(每窗) − 大惩罚(任窗击穿 dd_floor)`

- 样本外 70/30 验证；批量子进程跑 trial 防 OOM

可调整方向（按性价比排序）：

1. **Walk-forward 滚动**：把"一次 70/30 切分"改为"滚动训练/测试多折"，最后评分取多折样本外均值——对时序过拟合的打击比单次切分强得多。
2. **参数敏感度曲面**：对候选最优参数做邻域扰动（±1 档位），算绩效曲面的"平台宽度"。尖峰型最优=运气型过拟合，平台型最优=稳健，两者给不同信任分。
3. **参数去相关**：先做相关性分析，把强相关参数（如 atr\_multiplier 与 atr\_trail\_mult）合并/固定一个，减少名义自由度。
4. **样本外衰减监控**：寻优结果跑完后，按持有期外推时间分段看绩效衰减率，衰减快的方案自动降权。
5. **显著性过滤**：对候选参数做 bootstrap/蒙特卡洛，输出置信区间，过滤"运气型"高分。
6. **最小样本约束惩罚**：交易次数过少（\<N）或依赖极端个股的方案直接降权。

### 3.3 回测/模板 JSON 导入导出（用户提出，建议直接做）

价值：参数即代码，JSON 即"参数快照"——

- 模板/回测配置导出为单个 JSON 文件；导入即可复现。

- 跨设备/分享/版本管理（git 里 diff 参数变化，天然审计）。

- 配合**数据与代码版本指纹**（在 JSON 里写入：数据最后更新日、引擎 commit、seed），实现"完全可复现"，这是回测可信度的最后一块拼图。

实现成本低：后端已有一份 `buildConfigFromValues`（前端）与 `normalize_config`（后端）双向归一化函数，加两个端点（导出/导入）即可，前端加下载/上传按钮。

### 3.4 数据管理 —— 可靠性是第一优先级

已踩坑：缺日线 → 复权因子 fill\_null(1.0) → 后复权价突变 → pnl 算错。教训是"数据错了，策略分析全错"。

可调整方向：

- **完整性自检**：扫描各股票日线覆盖度（vs 交易日历），缺失自动补数或告警列表。

- **复权因子校验**：买卖跨日因子的异常跳变检测（价格突变阈值告警）。

- **多源交叉校验**：baostock 与东财同一股票同一区间收盘价对比，偏差>阈值告警。

- **数据版本化**：记录每次更新范围与时间，回测时可查"这份报告用的数据截止到哪天"。

### 3.5 实盘 —— 明确为终局，但分阶段

现状已有：盘前编排、盘中信号机、盘后复盘、飞书通知、影子运行、小资金就绪检查。

方向：

- P0：**实盘 vs 回测偏离监控**（影子运行的信号命中率、成交价差），这是验证策略"真伪"的关键数据。

- P1：实盘绩效归因（与回测同样口径的做T/加减仓分解）。

- P2（远期）：券商 API 一键执行。在此之前，手动执行+影子跟踪即可闭环。

### 3.6 AI 分析 —— 差异化点，往"归因"深挖

现状：后台任务生成报告（业绩点评/风险/参数建议）。

可调整方向：

- **失败交易归因**：对每笔亏损/止损，AI 判断"这是纪律性止损（对的）还是逻辑破坏（要改）"——把复盘从人工变成半自动。

- **事件驱动**：接入公告/新闻/龙虎榜，解释异动。

- **可执行输出**：报告末尾给"下一轮回测建议改哪几个参数"，与寻优打通。

## 4. 脑暴新方向（按投入分级）

### P0 · 低成本快赢（1\~2 天内可落地，纯增量）

1. **回测/模板 JSON 导入导出** —— 用户提出，见 3.3。✅ 已完成（2026-09）：新建回测表单支持导出当前配置/选中模板为 JSON、导入 JSON 回填表单。
2. **数据完整性自检面板** —— 覆盖率扫描 + 价格突变告警，直接堵"数据错了"的坑。✅ 已完成（2026-09）：数据管理页新增自检面板（缺口/价格突变/复权因子异常，全市场 250 交易日约 1.5s）。
3. **寻优结果一键"存为模板"** —— 最优参数直接生成可提交的回测模板，闭环"寻优→验证"。✅ 已完成（2026-09）：寻优详情页最优参数卡片加"存为模板"按钮，best_params 风控字段自动归位 risk_config。
4. **模板参数 diff** —— 选中两个模板/回测并排 diff 参数，方便 A/B 对照与审计。✅ 已完成（2026-09）：新建回测页"对比模板"弹窗，策略参数/风控/基础配置并排对比、差异高亮。
5. **做T审计报告导出** —— 现有做T纪律审计导出 CSV/JSON，便于外部统计。
6. **全市场特征缓存** —— momentum\_core 的日特征中间结果落盘（按数据版本+参数指纹缓存），动态选股/选股器/盘前全部提速。

### P1 · 中期（1\~2 周量级，核心价值）

1. **Walk-forward 滚动寻优 + 参数敏感度曲面** —— 3.2 的两项，防过拟合主战场。
2. **样本外绩效衰减监控** —— 回测完成后自动标注"样本外健康度"。
3. **实盘 vs 回测偏离监控** —— 3.5。
4. **失败交易 AI 归因** —— 3.6。
5. **组合层升级** —— 波动率目标仓位、行业/风格分散约束、组合级风险预算（与现有风控/回撤熔断联动）。
6. **回测报告自包含导出（HTML/PDF）** —— 一次点击出一份可分享的完整报告。

### P2 · 长期（探索性，需先验证再投）

1. **轻量 ML 选股层** —— 在动量特征上叠 GBDT 排序（替代手工加权），必须 walk-forward 验证，否则大概率过拟合。
2. **事件驱动因子** —— 公告/新闻情绪/龙虎榜，丰富信号来源。
3. **多周期/多市场** —— 分钟级完整覆盖、港股/美股（现有 global 数据接口可扩展）。
4. **参数治理体系** —— 参数注册表 + 变更审计 + 版本管理，团队化前置条件。
